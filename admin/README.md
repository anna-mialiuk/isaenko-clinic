# Панель Dr. Isaenko

Окремий застосунок у тому самому репозиторії. Код панелі **не потрапляє**
в бандл сайту: сайт лишився 507 КБ, панель збирається окремо в 206 КБ.

```
src/            сайт          → dist/            → dr-isaenko.com
admin/          панель        → dist/admin/      → dr-isaenko.com/admin
public/api/     PHP, спільний
```

## Розробка

```bash
npm run dev          # сайт, порт 5173
npm run dev:admin    # панель, порт 5174
```

Панель у dev-режимі проксує `/api` на `http://localhost:8877` — там має
працювати PHP:

```bash
cd public && php -S 127.0.0.1:8877 -t .
```

## Збірка

`npm run build` тепер збирає обидва застосунки й генерує sitemap.

## Установка на сервері

**1. Пароль.** Хеш генерується на сервері, пароль у відкритому вигляді
в конфіг не кладемо:

```bash
php -r 'echo password_hash("ваш_пароль", PASSWORD_DEFAULT), PHP_EOL;'
```

**2. nginx.** Додати два блоки з `nginx-admin.conf` у `server { }`,
перед `location ~ ^/api/.+\.php$`. Підставити хеш.

```bash
sudo nginx -t && sudo systemctl reload nginx
```

**3. Перевірка.**

```bash
curl -s -o /dev/null -w "%{http_code}\n" https://dr-isaenko.com/api/admin?action=leads
# очікуємо 401 — без авторизації доступу немає

curl -s -X POST https://dr-isaenko.com/api/admin?action=login \
  -d '{"user":"admin","password":"ваш_пароль"}'
# очікуємо {"ok":true}
```

Панель: `https://dr-isaenko.com/admin`

## Безпека

- сесія в httpOnly + Secure + SameSite=Strict cookie, 12 годин
- `password_hash` / `password_verify`, пароль ніде не зберігається відкрито
- `hash_equals` для логіна — щоб його не підібрали за часом відповіді
- 5 спроб входу за 15 хвилин з одного IP
- сервер не каже, логін чи пароль невірний
- `X-Robots-Tag: noindex` на панелі й на API

У панелі персональні дані пацієнтів — імена, телефони, повідомлення.
Доступ варто давати мінімальній кількості людей.

## Чого поки немає

**Демографія (стать, вік) і міста.** Живуть тільки в GA4 і вимагають
Google Analytics Data API зі службовим обліковим записом. Стать і вік
додатково потребують увімкненого Google Signals — для медичного сайту
це рішення варто окремо обговорити з клієнтом.

**Лог помилок.** Помилки форми зараз пишуться в `error_log` сервера.
Щоб бачити їх у панелі, потрібна окрема таблиця й запис у неї з `contact.php`.

**Кілька користувачів.** Зараз один логін на всіх. Якщо треба розділити
доступи менеджерів — потрібна таблиця користувачів і ролі.
